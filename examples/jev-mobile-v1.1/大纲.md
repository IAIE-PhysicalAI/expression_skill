# 《Jev 决策模型在 Mobile GUI Agent 领域的研究进展》大纲

## 写作方向与边界

- 核心问题：截至 2026-10-19，Jev 在 mobile GUI Agent 中有哪些直接研究、可归为哪些技术思路，各自得到什么证据，又有哪些尚未解决的工程问题。
- 读者与用途：面向已有 GUI Agent 背景的研发同事，突出系统分工、实验口径和可落地判断，压缩基础概念铺垫。
- 材料范围：只使用 `资料.md`。直接相关证据以 P01、P02 为核心；P03—P08 用于解释可迁移机制与证据边界；P09—P16 仅作为 mobile GUI 邻近路线对照；T01—T03 仅用于说明厂商接口，不作为论文证据。
- 总体判断：Jev 当前最有根据的定位是受工作流约束的快速决策层，而非成熟的端到端 GUI 策略模型。局部决策降本增速已有证据，能否转化为单位成功收益取决于候选覆盖、接口设计、恢复和终态验证。

## 1. 范围与结论先行（简要）

- 用一段话定义 Jev/TDM：对调用方给定的有限选项返回结构化选择与概率；厂商支持 Choice、Score、Noul。
- 明确检索边界：资料包的定向 arXiv 查询中，直接研究 Jev 与 mobile GUI 的核心论文只有 P01、P02；均为 2026 年预印本，不能写成系统性综述或成熟共识。
- 先给研发结论：适合高频、有界、可验证的局部动作选择；不适合独立承担开放式规划、树外视觉定位和复杂恢复。

## 2. 研究思路与证据

### 2.1 分层委派：低频 VLM 规划，高频 Jev 执行（详细展开）

- 以 P01 Jev-Mobile 为主：VLM 设局部目标和精确文本；程序从实时 accessibility tree 生成候选；Jev 在动作 ID、DONE、BLOCKED 中连续选择；每步重观测、重建候选。
- 解释关键价值来自三层分工，而非笼统的“小模型替代大模型”。
- 报告完整 AndroidWorld 的成功率，以及仅成功轨迹上的耗时和成本；明确两类指标的不同分母。
- 限制：树外视觉目标、非 ASCII 输入、长树、局部 DONE 与全局成功的区别，以及缺少同框架小 VLM 控制组。

### 2.2 模块替换：把 Jev 接入既有 Agent 工作流（详细展开）

- 以 P02 为主，聚焦 AndroidWorld 的 T3A、AutoDroid、FastAgent；ALFWorld 仅用于补充“工作流依赖性”，不喧宾夺主。
- 区分决策级收益、任务级收益和单位成功收益：五类 agent 的决策成本/时间均下降，但移动端成功率下降幅度不一；T3A 单位成功成本、FastAgent 单位成功时间恶化。
- 解释效率传导损失：辅助推理与环境开销、额外交互/接口粒度、失败恢复、过早完成。
- 提炼评测要求：全任务成功率、失败开销、匹配成功样本、cost/time per delivered success。

### 2.3 可迁移方向：视觉共享、端侧部署、动态动作空间（适度展开）

- P03 Visual Jev：共享视觉前缀、多问题隔离批处理；说明与 GUI 多判定的潜在结合，但没有 mobile GUI 端到端验证，且 T02 将图像/Box 标为试验功能。
- P04 Chinese-Jev：轻量 encoder 与手机端 INT8 演示仅证明端侧决策的可行性，不证明 GUI 控制能力。
- P06 JevSpawn：动态组合有限动作字段、并行分支和反馈恢复，回应固定候选限制；不是 mobile GUI 专项证据。
- P05 可作为“Jev 参与策略训练”的远期线索，限于 MiniGrid/Atari；不展开无关细节。

## 3. 与 Mobile GUI 邻近路线的关系（适度展开）

- 重点比较 P11 V-Droid：同属“候选生成 + 判别选择”，但其为经过偏好训练的 verifier，Jev-Mobile 为通用 typed decision 服务与显式交接。
- 简要定位 P09/P10/P12/P13/P15/P16：分别处理快慢感知、并行探索、RL 策略、视觉 grounding 或原生端到端 agent 等不同瓶颈。
- 给出组合式系统图景：结构化决策层 + 视觉 grounder + 慢 VLM 重规划 + 独立 verifier + 恢复策略。明确这是从材料推导的研发方向，不是已有系统的统一实验结论。

## 4. 研发判断、建议与证据边界（详细展开）

- 采用选择性委派：目标明确、候选覆盖充分、前置条件和预期变化可观察时才走 Jev；低置信、无进展、树与截图冲突时升级。
- 候选接口显式携带控件身份、前置条件、预期状态变化，并保留 none/BLOCKED。
- 动作选择与完成验证分离，避免局部 DONE 被当作全局成功。
- 对照设计：同一 controller、同一候选与预算下比较 Jev、小 VLM、规则/打分器；按任务难度和树覆盖率分层。
- 指标：覆盖率、选择准确率、交接正确率、恢复率、轨迹长度、全量成本和单位成功成本；中文端侧另测语义、输入、量化校准和真机时延。
- 重申：已有证据支持“快速、有界的执行/决策组件”，不支持“通用替代 VLM”。
- 直接论文数量少、模型闭源、系统接口与统计口径不统一；P08 的早期审计可用来佐证谨慎口径：主要优势在时延和成本，typed readout 尚无独立准确率优势。
- 保留全部实际引用到的原始来源链接；正文控制在约 2000—3000 个汉字，可因表格与必要限定小幅浮动。

## 待补充与校验重点
