## 实际执行

修订会话关闭自动技能目录、插件、记忆及外部检索，通过文件显式读取本次技能。会话没有继承前期实验的聊天历史；工作目录内只提供本次任务文件。读写范围由指令限制并结合工具记录核对，不声称具备操作系统级隔离。

| 阶段 | 记录中可观察到的行为 |
| --- | --- |
| 准备 | 读取入口、基础原则和阶段职责，保存大纲 |
| 补充信息 | 按大纲重新读取共同材料，保存出处、统计口径与缺口 |
| 内容编辑 | 修改同一份正文，压缩背景并区分直接研究、迁移线索与邻近路线 |
| 组织验收 | 读取该阶段指令后重新读取正文与大纲，通过 |
| 逐句支撑验收 | 读取该阶段指令后重新读取正文与依据，发现两处表述超出证据范围 |
| 修复与复验 | 回到内容编辑修正；再次读取支撑验收指令、完整正文和依据后复验 |
| 个性化风格 | 读取职责，认为当前文风合适，无额外风格修改；随后检查文件与链接对应关系 |

两处定向修复分别是：将“这些结果证明了完整系统的效率”改成限定实验设置与统计口径的判断；将“更合理的组合”改为待验证的候选架构。V-Droid 的表述也从初稿中的在线 `pair-wise progress` 判断收窄为“经过偏好训练的 verifier”，与资料提供的训练描述对应。

公开操作记录只提取命令、文件变更和对用户的阶段进度，本机绝对路径已归一化；不公开内部推理、认证信息或原始工具输出。校验记录中的“通过”是执行 Agent 的判断。

## 发布者复核与局限

- **仍有遗漏。** 正文保留 T3A 单位成功成本从 68.70 升至 73.97 mUSD 的均值变化，但没有同时说明 P02 报告的增幅置信区间跨零。读者应将其视为该实验的观察均值，不能据此认定稳定退化。
- **分类可继续解释。** 分类表包含控制结构、输入模态和部署位置等不同维度，作为研究地图可用，但这些方向并不互斥；当前正文未充分解释组合关系。
- **篇幅有所收缩。** 按 Unicode 汉字计数，初稿约 2088 字，修订稿约 1743 字，短于任务建议的 2000～3000 字。任务允许适度浮动，发布者保留实际产物，供读者判断压缩是否合适；Agent 记录中的非 ASCII 字符数包含标点，不能当作汉字数。
- **流程不等于效果证明。** 这次明确执行了验收阶段回读和定向复验，仍存在上述内容问题。正反表达检查已在所用规则中，但本例不能证明已消除所有防备性修辞。
- **不是等预算对照。** 修订比初稿多一次编辑机会；没有增加同初稿、同材料、不使用技能的第二次润色组，也没有为本例另做模型盲评。它展示使用过程，不用于证明普遍效果提升。
