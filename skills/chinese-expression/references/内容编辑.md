# 内容编辑：第五步

本轮根据大纲、材料和待修复问题修改当前正文。检查沿用主入口的当前模式，默认由当前 agent 完成。

逐段确定：这一段表达什么、在全文起什么作用；哪些信息足以解释或支持它；怎样排列才能让读者逐步理解。想法决定选取什么，逻辑决定怎样组织，不围绕已有资料硬凑观点。

- 保留仍然有效的信息和表达，只因具体问题修改。重组主线确有必要时可调整全文，不能把每轮修改变成从头再写。
- 重点落实到充分解释与依据，背景控制范围。判断缺依据就补材料，过程难懂可用明确标识的假设例子，结论有范围就交代条件。不要求每段有例子。
- 并列信息可以并列呈现；承接必须真实，不靠强加关联词制造推进。
- 保持句内和句间的对象、条件、因果、指代清楚。按读者首次遇到的顺序检查概念，理解所需的解释须先于依赖它的内容，辅助概念也不遗漏；跨段统一称呼，分清相似概念。数字和判断补足理解所需的前提与关联。
- 结构、重点或关键限定变化时，同步保存大纲。每轮可处理一个段落、相关段落组或章节，不强求改动数量。

修复时先定位问题与关联内容，针对本轮问题定向修改。发现输入理解错误回准备阶段；依据不足回补充信息阶段；不靠语言顺滑掩盖问题。关键立场或边界需要作者决定时，说明缺口并暂停相关处理。

交接：正文及必要的大纲调整已保存，按主入口当前模式检查实际内容。首次完整验收进入组织检查；修复后按《交接协议》复验。只说明修改位置、关联影响与未解决问题，不把完成声明当作通过依据。
