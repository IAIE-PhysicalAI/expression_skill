# 个性化风格：第七步

进入条件是当前内容已有提问 agent 给出的、仍有效的组织与逐句支撑通过结论。已有结论失效或尚未做必要检查时先安排相应验收；不能自行假定内容成立。本轮只处理真正因人而异的表达特点；准确、熟悉的词汇、去冗余和修辞适度始终遵守基础原则，不留到此时才做。

根据原稿、参考文本或明确偏好，调整语气、节奏、句式与口语化程度，保留作者有效且有辨识度的表达。直接、克制、温和、幽默或犀利都可成立，不把所有文章改成同一种正式文风。

没有风格依据时克制修改。已经合适可不改，不为凑轮次强行替换词句。不得改变事实、原意、条件和已有逻辑；发现内容问题应交回对应阶段处理。

交接：必要的风格修改已保存，向同一个提问 agent 提交修改后复验，按《交接协议》检查风格要求及内容影响。没有实际修改且原结论仍有效时可直接交付；一旦改动，不能由风格方自行宣布无需复验。
