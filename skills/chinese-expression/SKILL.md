# 语言表达：写作与检查

## 目标与职责

以中文完成写作与编辑。**想法驱动，信息支撑。想法决定需要表达什么，逻辑决定如何组织与表达信息。** 想法接受事实检验，不挑选依据迎合预设结论；任务目标不转成必写内容、唯一观点或固定答案清单。

你负责准备、补充信息、编辑、风格调整、定向修复、检查、用户沟通与交付。默认全程由当前一个 agent 完成。

先读取[表达原则](../../shared/表达原则.md)和[交接协议](../../shared/交接协议.md)，再按当前阶段读取方法。交接协议中的检查标准与状态适用于两种模式，跨 agent 的提交与问题关闭规则仅用于严格校验模式。

## 执行模式

- **默认单 agent**：写作、润色、局部修改、风格调整、仅检查和后续追问都由当前 agent 执行，不创建、初始化或调用子 agent。检查时直接读取下表中的检查方法，不切换为只读验收角色。
- **严格校验模式**：只有用户明确要求使用“严格校验模式”才启用一个提问／验收子 agent，此时再读取[严格校验模式](references/严格校验模式.md)。当前稿件任务已明确启用且未撤销时可沿用；新任务默认回到单 agent，用户要求单 agent 或退出严格校验时停止后续派发。
- “仔细检查”“严格检查”“检查逻辑”“多检查几遍”、稿件较长或任务复杂都不等于启用严格校验模式。讨论、引用或修改模式规则也不构成启用请求；不要自行升级模式，也不主动要求用户选择模式。

仅解释文意、来源位置或修改理由时，读取必要内容后直接回答。

## 按阶段写作与检查

用户要求撰写、改写实验报告，或明确选择按实验报告组织内容时，在准备或接续编辑前加读可选模块[实验报告](references/实验报告.md)，用于后续大纲、正文和验收。仅讨论实验内容时不自动加载。

| 阶段 | 本轮读取 | 产物 |
| --- | --- | --- |
| 准备：第一至三步 | [准备](references/准备.md) | 已保存的大纲与有效用户需求 |
| 补充信息：第四步 | [补充信息](references/补充信息.md) | 可用依据、出处、条件与未解决缺口 |
| 内容编辑：第五步 | [内容编辑](references/内容编辑.md) | 已保存正文及必要的大纲调整，待验收 |
| 内容验收：第六步 | [组织验收](../chinese-expression-review/references/组织验收.md)，再读取[支撑验收](../chinese-expression-review/references/支撑验收.md) | 当前版本与相关范围的检查结论或实际问题 |
| 个性化风格：第七步 | [风格调整](references/风格调整.md) | 必要的风格修改，待复验 |
| 修改后复验 | [修改后复验](../chinese-expression-review/references/修改后复验.md) | 原问题及修改影响的复查结果 |

第一至三步合并，其余阶段分别执行；每轮只加载共同规则、本轮方法和必要输入。已有合适大纲、材料或表达直接复用，检索按需进行，不为体现流程制造内容。

润色使用指定文档，未指定原地修改时先建立工作副本；新写作建立正文文件。各轮维护同一正文，大纲保存在旁边，材料沿用原有笔记。正文、大纲与材料由你维护；严格校验模式中的提问方只读取并返回检查结果。

## 提交、回退与再次检查

保存产物后，重新读取当前版本、有效要求和必要原始依据，按检查方法回读。默认模式中由你顺序完成检查、定向修复和复验，不模拟双方交接，不因切换检查类型等待外部执行轮次。严格校验模式按专用参考向同一个提问子 agent 提交检查。

首次完整内容验收先检查组织；组织有问题，定向修复并复验，通过后再检查支撑。发现支撑问题回到责任阶段处理；改动影响组织时先重新组织验收，再继续支撑。风格阶段需已有相关范围内仍有效的组织与支撑通过结论，实际风格修改后完成修改后复验。

修复保存后先标记待复验，实际回读原问题及修改影响后才可关闭。默认模式由当前 agent 完成这一判断，不能以“已经改了”代替复查；严格校验模式由提问方确认关闭。

用户围绕已有稿件追问、补充信息或要求再次修改时，先读取[追问与修改](references/追问与修改.md)，判断从哪个阶段接续。仅要求检查时按当前模式完成指定检查并返回结果，不修改正文、不强制补纲或执行未请求的检查。

## 交付与能力边界

最终提交前清理正文中的修改说明、对话应答、占位符和服务邀约，并同步必要大纲。按当前模式完成所需检查，结论仍覆盖交付版本且无未解决实质问题，才交付为已检查稿；检查后再次改动，完成必要复验。默认模式的自检不称为独立验收。直接交付已保存的正文与大纲位置，不另写未检查的新稿，也不额外索取满意度或审批。

默认模式只需相应的文件读写及任务所需工具；仅严格校验模式依赖子 agent 调度能力。能力不足或检查未完成时说明实际限制和当前状态，不模拟核验或宣告通过。外部检索遵守已有授权，不修改用户全局技能或模型配置。明确资源上限已达到时交付未完成状态，不以耗尽资源代替完成。

本源包与验收 skill 配套使用。分发时保持两个角色目录及共享文件的关系，或将共享规则随两个 skill 一并打包，避免只复制某个入口造成引用缺失。
