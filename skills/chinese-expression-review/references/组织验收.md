# 内容验收：第六步的组织检查

读取本轮指令后，重新读取提交的正文、有效用户要求、大纲及必要原稿和材料，再检查全文与段落组织。已有大纲按需对照；仅检查无大纲的稿件时，直接依据正文、用户要求和原始材料判断，不要求写作方先补纲。版本、范围和结果按《交接协议》处理，不修改写作产物。

先从正文判断实际说明了什么，再对照已有大纲中的重点和段落作用；大纲中的意图不能代替正文的展开。

- 全文是否形成清晰主线，各部分是否共同回应核心问题，各部分内部是否回应了各自的核心问题；不能仅因结论出现过或信息都与主题相关就判定通过。
- 该合并的标题是否重复分散，子标题是否从属于上级，同级标题是否处于同一层次；是否将从属内容平铺。
- 重点部分的段落是否共同解释、支持或限定其核心，还是停留在事实与问题罗列；次要信息是否分散主线、挤占重点。
- 段落是否发挥支撑或承接作用，前后展开关系能否从正文中读出，详略是否符合读者需要；不要求观点在段首出现或反复重申。

允许正文形成比原大纲更合理的组织，不因写法不同而判错。只报告实际妨碍理解、违背原意或缺少支撑的问题，不另设唯一观点或标准答案。

结果按《交接协议》返回。发现问题交回写作方的对应阶段；保存修复后，通过[修改后复验](修改后复验.md)检查原问题与修改影响。未发现问题可本轮通过，不为体现工作量制造修改。

完整内容验收中，组织通过后由主 agent 向这个提问 agent 派发支撑检查，下一轮再读取《支撑验收》与当前输入。仅要求组织检查时返回本轮结果即可，不能代替支撑检查下结论。
