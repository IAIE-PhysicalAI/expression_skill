# 内容验收：第六步的逐句检查

读取本轮指令后，重新读取提交的正文、有效用户要求、必要原稿和依据，再检查段内每句话的信息与关系。组织检查时读过正文不代替本轮回读，组织通过不证明逐句支撑成立。版本、范围和结果按《交接协议》处理，不修改写作产物。

- 句子：前后信息衔接是否顺畅，有无跳跃、重复、指代不清或关系不明。
- 支撑：每句话是否承担解释、证据、条件、推理或必要承接的作用；它背后是否有足够的信息及关联信息，这些信息合在一起是否支持段落观点。
- 核心信息孤立：概念、判断、数据或例子是否只被提及，未解释理解所需的含义、前提、条件或与当前观点的关系。
- 推理：是否把相关当因果、个例当普遍结论、省略关键前提；关联词声称的关系是否成立，正反对比是否真的可比。
- 正反表达：检查“不是……而是……”“并非……”“这不意味着”等反面结构是否实际承担排除常见误读、区分相近概念或限定证据边界的作用。只将没有实际解释、区分或限定作用的重复防备、虚设反方判为冗余，指出具体影响，将改为正面陈述、合并或删除作为修复方向交回写作方。删减后须同时保留观点、必要条件与证据边界；核心意思仍在不证明限定可以删除。
- 忠实与依据：是否新增无依据的信息、改变原意或确定性；来源是否支持当前范围。固定资料无法核实的内容保留限制，不能因无法联网而猜测答案。

支撑可来自上下文和已引入材料，不要求每句话另配引文或例子。检查提交范围内全部适用内容，长文由这个提问 agent 分段读取并检查边界；不能以抽查几句代表逐句验收，也不能将局部检查说成全文通过。

已有信息但没讲清楚，交回写作方的内容编辑；缺少依据，交回补充信息；误解原意或材料，交回准备。保存修复后，通过[修改后复验](修改后复验.md)检查原问题及修改影响；影响组织时先交回组织复验。

结果按《交接协议》返回。文字读起来顺畅不能代替逻辑成立；修改者声称完成也不能代替本轮判断。检查实际读取的来源是否支持当前表述，不把写作方的材料摘要或核实声明当作来源本身。
